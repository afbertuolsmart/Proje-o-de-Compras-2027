# Dashboard de Consumo por Cor e Material

Projeto React + Vite para rodar no VS Code.

## Instalação

Abra a pasta no VS Code e execute no terminal:

```bash
npm install
npm run dev
```

Depois abra o endereço exibido pelo Vite.

## Dados

A planilha usada está em:

`public/data/Consumo.xlsx`

O dashboard lê a planilha no navegador. Para atualizar os dados, substitua esse arquivo mantendo as colunas usadas pelo projeto.

## Estrutura

- `src/App.jsx` — dashboard e regras de análise
- `src/styles.css` — visual
- `public/data/Consumo.xlsx` — fonte de dados
- `package.json` — dependências e scripts
